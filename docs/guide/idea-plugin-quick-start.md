# IDEA 插件首次使用

Java Source Atlas IDEA 插件有两种使用方式：在普通业务项目中阅读教程、定位当前依赖源码；在完整 `java-source-atlas` 仓库中运行 Lab，并通过推荐断点调试精确的 JUnit 证据场景。

正式发布后可以在 IDEA 的 `Settings | Plugins | Marketplace` 中搜索 `Java Source Atlas` 安装，
也可以从 GitHub Releases 下载 ZIP，再通过 `Install Plugin from Disk...` 安装。Marketplace 版本
支持 IDEA 自动发现更新；首次审核完成前仍以 GitHub Release 为可用安装入口。

## 第一次打开

安装插件并重启 IDEA 后，打开右侧 `Source Atlas` 工具窗口。插件首次打开会自动进入“环境检查”，以后可以随时从专题导航的同名页签重新进入。

环境页会检查以下条件：

| 检查项 | 就绪条件 | 未就绪时怎样处理 |
| --- | --- | --- |
| 教程站点 | 插件配置的教程根地址返回成功响应 | 点击“教程设置”检查地址，或点击“重新检测”重试网络访问 |
| 项目 JDK | 当前 IDEA 项目已经配置 Project SDK | 在 `Project Structure` 中选择项目使用的 JDK |
| Maven 与仓库 | 项目根目录同时存在 `pom.xml`、`source-index` 和 `labs` | 需要调试 Lab 时，点击“项目仓库”并用 IDEA 打开完整仓库根目录 |
| 当前源码入口 | IDEA 可以在项目或依赖源码中解析所选类和方法 | 为 JDK 或 Maven 依赖下载并附加源码，然后重新检测 |
| 当前 Lab 模块 | 索引声明的 Lab 主类已经进入 IDEA 类路径 | 重新加载根 Maven 工程，确认对应 `labs` 模块已经导入 |
| 当前 JUnit 场景 | 所选断点绑定的测试类和方法已经导入 | 在“推荐断点”页选择带“可调试场景”标记的断点，并刷新 Maven |
| IDE 内教程 | 当前 IDEA 运行环境提供 JCEF | JCEF 不可用时不影响其他功能，教程会回退到系统浏览器 |

普通业务项目通常不会通过“完整 Atlas 仓库”和“Lab 模块”两项检查，这是正常状态。此时仍可使用专题搜索、IDE 内阅读、浏览器阅读、源码定位和版本提示；只有运行教学 Lab 与精确 JUnit 场景需要打开完整仓库。

检查项未就绪时，状态行右侧会直接显示对应操作：JDK 可以进入 SDK 配置，Spring 依赖可以触发 Maven 下载源码，Lab 或测试缺失时可以重新导入 Maven，未选择测试场景时可以直接进入推荐断点页。

## 阅读当前项目中的源码

1. 在业务代码、JDK 类或 Spring 类中放置光标，打开 `Source Atlas`。
2. 插件自动匹配专题；也可以在“专题”页搜索类名、方法或专题名称。
3. 进入“源码”，点击“继续阅读”恢复上次方法；首次阅读会从第一个入口开始。
4. 在“入口列表”使用“上一个”“下一个”沿调用链连续定位，或切换到“当前方法”查看职责、执行过程、设计亮点、易错点和关联方法。
5. 返回“专题”页，使用“IDE 内阅读”或“浏览器打开”查看对应讲解。

如果“定位源码”不可用，先在环境检查中确认“当前源码入口”。JDK 源码可以通过 IDEA 的 `Download Sources` 或本机完整 JDK 安装附加；Spring 源码由 Maven/Gradle 下载对应 source JAR 后即可解析。

插件会保存上次方法、文档锚点、教程版本、已经打开的入口和已经准备的断点。下次选择同一专题时会恢复到上次方法，而不是重新回到第一项。

“跟随编辑器”只刷新“当前方法”讲解和同一专题内的入口高亮，不会把工具窗口强制切换到另一个专题。临时关闭跟随后，可以从入口列表自由比较多个方法；需要重新读取光标位置时点击“同步当前方法”。关联方法支持双击定位，显式关联尚未配置的旧专题会回退到前一个和后一个阅读入口。

## 翻译源码注释

Source Atlas 不修改 JDK 或依赖中的只读源码，而是把翻译交给 [Translation](https://plugins.jetbrains.com/plugin/8579-translation) 插件展示：

1. 安装并启用 Translation，在它的设置中选择翻译引擎和目标语言。
2. 把光标放到源码注释中，或放到带 Javadoc 的当前方法中。
3. 在“源码”页点击“翻译注释”，也可以使用编辑器右键菜单中的 `Java Source Atlas | 翻译当前源码注释`。
4. 需要连续阅读时勾选“定位后翻译”，以后从入口列表定位源码会自动触发当前方法 Javadoc 翻译。

未安装或未启用 Translation 时，插件会提供“打开 IDEA 插件设置”和“浏览器查看”两个入口。Translation 的 Reader Mode 行内文档翻译仍由 Translation 自己管理，Source Atlas 只调用其公开注册的编辑器动作，不读取或改写第三方插件配置。

## 使用编辑器上下文动作

在已经收录的 Java 类或方法中右键，打开 `Java Source Atlas` 子菜单，可以直接执行：

- 查看当前方法解析；
- 定位当前源码入口；
- 翻译当前源码注释；
- 添加当前方法推荐断点；
- 添加断点并 Debug 当前证据场景；
- 进入专题调用链下一入口；
- 收藏或取消收藏当前专题。

这些动作都可以在 `Settings | Keymap` 中搜索 `Java Source Atlas` 后绑定快捷键。动作会优先使用光标命中的方法；光标只停在类中时，会恢复该专题上次阅读的入口。

## 一次命中推荐断点

调试教学场景前，用 IDEA 打开完整仓库根目录并导入 Maven 工程。确认环境检查中的“当前源码入口”“当前 Lab 模块”均已就绪后：

1. 选择专题并进入“推荐断点”。
2. 选择带“可调试场景”标记的断点。
3. 点击“添加断点并 Debug”。
4. 插件先进入已附加源码，把 Java 行断点添加到方法体第一条可执行语句；同文件同一行已有断点时自动复用。
5. 断点确认存在后，插件创建只运行该证据测试方法的临时 JUnit Debug 配置。
6. 命中后对照列表中的观察场景、变量，以及按钮悬浮提示中的预期结果检查执行状态。

如果只找到方法声明、没有已附加源码中的真实方法体，插件不会创建无法命中的声明行断点，也不会启动一个注定无法暂停的测试，而是提示先附加源码。测试方法无法解析时，则需要重新导入对应 Lab 模块。

选择推荐断点后，页面下方会单独展示观察场景、预期结果和变量表达式。可以先“复制观察变量”；Debug 会话启动后，再点击“添加 Watches”把尚未存在的表达式一次加入 IDEA Watches。

“断点管理”只处理插件自己新建的断点，可以统一启用或禁用，也可以清理当前专题或全部 Atlas 断点。若同一文件同一行原本已有用户断点，插件只会复用，不会把它登记为 Atlas 断点，因此后续清理不会误删。

当 Debug 会话命中插件创建的 Atlas 断点时，“断点”页会自动恢复对应专题和方法，并展示本次
需要验证的结论、预期状态与下一推荐断点。观察变量仍由用户决定是否加入 Watches，插件不会在
后台执行可能改变程序状态的求值表达式。普通用户断点不会触发这组教学提示。

## JDK 与版本边界

插件使用 Java 21 构建，这是 IDEA 插件开发工具链要求，不表示所有 Lab 必须使用 JDK 21。JDK 专题以 OpenJDK 8u 为主要讲解基线，部分专题提供 JDK 17、21 对比；调试前应同时查看工具窗口中的项目版本、教程基线和兼容提示。

Spring Framework Lab 基于 Spring 5.3.39，Spring Boot Lab 基于 Spring Boot 2.7.18。业务项目版本不一致时，可以阅读公开契约和调用链，但私有方法断点是否存在应以当前项目实际依赖版本为准。

## 常见恢复路径

| 现象 | 优先处理 |
| --- | --- |
| 教程页空白或无法访问 | 在环境检查中重新探测；必要时打开“教程设置”核对根地址 |
| IDEA 内教程不可用 | 使用“浏览器打开”；这不会影响源码定位和断点功能 |
| “打开 Lab”不可用 | 打开完整仓库根目录，重新加载 Maven 项目 |
| “添加断点并 Debug”不可用 | 选择带可调试标记的断点，并确认对应测试模块已经导入 |
| 点击后提示没有找到断点方法 | 下载对应源码，或核对当前 JDK/Spring 版本是否包含该私有方法 |
| JUnit 启动但没有暂停 | 确认使用的是“添加断点并 Debug”，并检查断点没有被 IDEA 全局静音 |

环境信息仍不足以定位问题时，可以按照[反馈与问题定位](./feedback.md)提交插件版本、IDEA 版本、项目 JDK、专题与复现步骤。
